# Поиск самой длинной серии в матрице

Автор: Платонова Софья  
Группа: ПИ-261  
Вариант: 22

## Условие задачи

Для заданной целочисленной квадратной матрицы F найти номер строки,
в которой находится самая длинная серия.

Серия — последовательность одинаковых элементов, расположенных
подряд в одной строке. Одиночный элемент считается серией длины 1.

## Входные данные

Матрица размером 3 × 3. Элементы вводятся с клавиатуры построчно.
Размер матрицы задаётся константой maxCount.

## Выходные данные

- Исходная матрица в виде таблицы.
- Длины всех серий для каждой строки.


## Алгоритм решения

1. Ввести и вывести матрицу.
2. Последовательно просмотреть элементы каждой строки.
3. Подсчитать длины серий одинаковых элементов.
4. Вывести длину каждой серии и сравнить её с максимальной.
5. Вывести номер найденной строки и максимальную длину серии.
